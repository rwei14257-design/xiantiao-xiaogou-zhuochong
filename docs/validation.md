# v1.1.0 验证范围

日期：2026-10-17。

- 自动检查覆盖设置恢复、屏幕边界、缺图回退、素材路径、导入别名与格式替换、伪装文件拒绝、发布过滤、作息时间边界、跨午夜睡眠、冲突优先级、下一状态、周末和手动互动恢复。
- Windows Electron 42.4.1 实际启动验证：12 个状态卡片、尺寸切换、置顶、隐藏与唤回、重置位置、作息编辑与恢复通过；渲染控制台没有错误。
- 面板截图已人工检查；页面允许纵向滚动，没有页面水平溢出。时间轴可以横向滚动。
- 公开文件过滤拒绝角色 GIF、PNG、WebP、用户素材目录或本机程序。安装包构建后另行检查 app.asar 内容。
- GitHub Actions 在 Windows x64、macOS Intel 和 Apple Silicon 各自系统上安装官方依赖、运行检查、构建安装包。三个构建全部通过才发布 Release 与 SHA-256 校验文件；实际结果见仓库 Actions。

本地界面验证使用已有的同版本 Electron 运行时，因为本机官方下载较慢；该运行时未用于公开打包。构建通过不等于全部目标设备的安装和交互验证：尚未覆盖 macOS 真机完整交互、干净系统安装和多显示器组合。Windows 安装包没有商业签名；macOS 仅有 ad-hoc 签名，没有 Apple Developer ID 签名或公证。

此记录说明测试范围，不是法律审核或不侵权证明。版权核查见 [rights-review.md](rights-review.md)。
