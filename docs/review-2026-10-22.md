# happy dog 代码检查与优化

检查日期：2026-10-22。基于 v1.1.4 后的本地源码，未生成新版本安装包。

## 修复

- 重复启动：未取得单实例锁的进程退出时不再写入设置，避免覆盖正在运行的主进程设置；窗口尚未创建时收到第二次启动请求，会延后打开小屋。
- 作息提示：固定动作和手动互动期间，同步更新下一事件、时间范围和周末信息，不再仅依赖动作标识判断是否更新。
- 定时计算：保留每秒到期检查，普通作息计算按分钟进行；两分钟互动到期和系统唤醒仍立即重新计算。向小屋和桌宠广播同一份状态，避免重复计算。
- 点击穿透：按图片的实际宽高比采样，匹配页面 object-fit: contain 的显示区域；横图上下留白不再被误判为小狗。缓存透明度数据，减少鼠标移动时的画布读取；窗口隐藏时跳过采样。
- 页面更新：时间线内容没有变化时复用原有节点，仅更新当前状态标记；同一图片地址不重复赋值，避免无谓重启动画。

## 验证

- 16 项 Node 自动测试通过，其中新增 4 项生命周期回归测试，覆盖第二进程退出、启动时序、固定状态的下一事件更新、分钟内的手动模式到期，以及广播复用。
- Windows Electron 42.4.1 实际启动测试通过，分别验证公开源码版本和本机内置动画版本：12 个状态图像、横图透明留白点击判断、尺寸切换、置顶、隐藏与恢复、面板交互、作息保存及恢复。
- 面板交互后时间线节点保持复用；两次实际启动测试均没有渲染控制台错误。
- 本机程序同步了修复，原有线条小狗动画与用户设置保留。
- 本轮未在 macOS 真机运行，未重建或发布 GitHub 安装包。

此记录只覆盖本轮检查和测试，不代表对所有平台和边界情况的完整保证。
