# 小狗的一天 · v1.1.0

线条小狗仍是目标萌宠。这一版围绕「作息陪伴」重新设计，提供 Windows 与 macOS 应用安装包。

## 下载

- Windows 10 / 11，64 位：`Puppy-Companion-1.1.0-Windows-x64-Setup.exe`。
- Apple Silicon（M 系列）Mac：`Puppy-Companion-1.1.0-macOS-arm64.dmg`。
- Intel Mac：`Puppy-Companion-1.1.0-macOS-x64.dmg`。
- `SHA256SUMS.txt` 提供下载文件校验值。

## 新内容

- 六个可调整时间：起床、早餐、午餐、下班、晚餐、睡觉。
- 早安、三餐、午休、喝水、伸展、下班、睡前放松及跨午夜睡眠；区分工作日和周末。
- 点击互动保留 2 分钟，然后回到当前作息，也可立即恢复或固定动作。
- 小屋新增今日时间线、当前状态、下一计划、时间编辑器。
- 12 个状态槽位，新增睡前放松和完成庆祝；每个状态均有说明和不包含角色形象的功能示意图。
- 素材文件夹导入、格式和大小检查、缺图回退；素材存入应用数据目录，升级不覆盖。

## 安装与素材

安装包包含官方 Electron 运行时，用户无需另装 Node.js。首次启动进入小屋，通过「导入本地素材」选择自己有权使用的线条小狗 GIF / PNG / WebP。应用和安装包**不包含线条小狗角色素材**，未导入的状态显示功能示意图，不会换成其他萌宠。

这是非官方项目。学习、非商业和侵删声明不等于素材授权，MIT 只覆盖本项目有权许可的内容。详细边界见仓库 `NOTICE.md`、`ASSET_POLICY.md` 和 `docs/resource-research.md`。

## 当前限制

Windows 安装包未进行可信发布者证书签名；macOS 使用 ad-hoc 签名，没有 Apple Developer ID 签名和公证，系统可能提示无法验证开发者。请核对仓库和校验值；macOS 可按系统「隐私与安全性」提供的流程处理，不需要关闭系统整体安全防护。

Windows 本机已验证界面；Mac 安装包在对应架构的 GitHub macOS runner 构建，尚未经真实用户设备的完整安装与交互验收。没有全局键盘监听、音乐软件监听或开机自启功能。
