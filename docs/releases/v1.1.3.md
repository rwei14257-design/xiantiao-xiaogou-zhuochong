# v1.1.3 · 双狗合照图标

- 使用浅棕小狗与白色小狗相拥的合照应用图标。
- Windows 程序、安装器、卸载器及快捷方式采用多尺寸 ICO；macOS 使用含 1024 像素图层的 ICNS。
- 窗口、系统托盘与小屋品牌区域统一图标。
- 保留每日作息、12 个动作和已有本地素材。

本版附带已登记的应用图标，不附带原始角色动画包。合照图标涉及第三方角色，不属于代码 MIT 许可，尚未取得角色公开展示及分发授权；详见 resources/icons/README.md 和 NOTICE.md。Windows 无商业签名，macOS 为 ad-hoc 签名、未公证。下载对应平台安装包，SHA256SUMS.txt 提供校验值。
