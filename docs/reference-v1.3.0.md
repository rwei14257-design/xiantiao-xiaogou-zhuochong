# v1.3.0 互动对照与验证

对照 [desktop-pets 的源码](https://github.com/remake1026/desktop-pets/tree/0529f64b521f32e28140bb3d07d0985ef905a7da/%E6%BA%90%E7%A0%81) 中的窗口、渲染器和输入辅助程序，以下行为在 happy dog 的 Electron、作息和素材模块中独立实现。

| 参考体验 | happy dog 中如何使用 |
| --- | --- |
| 鼠标停在小狗上、拖动、滚轮 | 空闲悬停蹦跳、拖动反馈、滚轮翻滚；透明边缘仍能穿透。点击和专注优先于悬停。 |
| 角落缩放 | 在工具条拖 ↘，或聚焦后按方向键微调；连续大小限制为 120–420，保留小屋里的三档快捷选择。 |
| 键盘反馈 | 小狗获得焦点时响应回车、删除、Ctrl/Cmd+S、Ctrl/Cmd+Z；另有默认关闭的跨应用监听开关。 |
| 每日固定动作 | 小屋「调整我的作息时间」中勾选「参考作息」；按时吃饭、阅读、喝水、下班和睡觉。取消勾选即切回原先的个人时刻。 |
| 520、521 彩蛋 | 自动作息下在 05:20、05:21、17:20、17:21 显示；用户主动点击的 5 秒表情优先。 |
| 开机、缓存、任务完成 | 托盘可设置登录启动、只清理页面缓存、播放庆祝。启动参数 `--task-complete` 支持冷启动和通知已有实例。 |

仍沿用 happy dog 的无对白、5 秒互动、音乐舞池、25 分钟专注和四款惊喜。Windows 音乐检测使用系统媒体会话，Mac 使用 Music/Spotify 的播放状态；并非参考项目的原生音频实现。公开包支持 Windows x64 以及 Apple Silicon / Intel Mac，没有提供 Windows x86 包。

**Windows 验证：**28 项自动测试通过。另用实际 Electron 窗口验证连续缩放、输入动作和置顶切换；用独立配置启动两个进程，验证冷启动庆祝、已有实例庆祝、保存快捷键及手柄键盘微调。Windows 原生监听器已编译并成功注册钩子；没有修改用户的登录启动或跨应用监听偏好。

系统输入辅助程序随安装包提供，开启后只将预定义动作名发给桌宠；不记录文字内容。macOS 可能要求在系统设置中授予输入监控或辅助功能权限。Mac 真机上的全局输入权限流程未在本次 Windows 工作环境中验证。
