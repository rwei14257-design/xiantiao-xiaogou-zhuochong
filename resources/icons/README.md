# 双狗合照应用图标

日期：2026-10-18；自 v1.1.3 使用。

图标沿用用户本机已有 special.gif 的浅棕小狗和白色小狗相拥姿态，通过内置图像生成工具辅助制作，再导出各平台所需尺寸。该源 GIF 来自用户提供的参考应用素材，未逐一核实原始 GIF 制作者。线条小狗角色权利属于相应权利人，本项目没有取得公开展示、改编或随应用分发的角色授权；AI 辅助生成、注明出处和免责声明不替代授权。这里的 PNG、ICO、ICNS 不按本项目代码 MIT 许可授权。

| 文件 | 用途 |
| --- | --- |
| icon.png | 1024×1024 应用图标和 README 预览 |
| icon.ico | Windows EXE、安装器、卸载器；16/24/32/48/64/128/256 像素 |
| icon.icns | macOS 应用；16/32/64/128/256/512/1024 像素 |
| ../../src/assets/app-icon.png | 256×256，窗口与小屋品牌图标 |
| ../../src/assets/tray-icon.png | 32×32，系统托盘图标 |

应用附带这枚身份图标，但不附带原始角色动画包；用户动作素材仍需自行导入。外部角色权利信息与反馈方式见 [NOTICE](../../NOTICE.md) 和 [截图来源记录](../../docs/screenshots.md)。
